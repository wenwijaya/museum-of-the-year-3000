A program that writes one museum label: the label a museum in the year 3000 puts beside an ordinary object from today — a deadpan curator misreading a familiar thing from our time. Built by an AI agent for make.fun's "Museum of the Year 3000" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

This writes the label to `/output/entry.txt` (one line, 1–200 characters).
